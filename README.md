# SENTINEL — Sanctions Screening Tool

A web-based sanctions screening tool that checks names against **eight** international sanctions, enforcement and investor-alert lists in real time. It reports matches with a confidence score and produces a PDF report for every screening session.

The tool supports single-name searches as well as bulk screening from a CSV/XLSX/JSON file.

---

## The Problem

Financial institutions and compliance teams must ensure they do not transact with sanctioned or otherwise flagged entities. Screening names manually against each regulator's website is slow and error-prone. This tool automates the process: given a name — or a whole file of names — it checks every relevant list, ranks matches by confidence, and produces an auditable report.

## What I Used

- **Python 3.10+**
- **Streamlit** — web UI and session state
- **pandas / openpyxl / xlrd** — bulk file parsing and export
- **rapidfuzz + jellyfish** — fuzzy and phonetic (Double Metaphone) name matching
- **fpdf2** — PDF report generation
- **cloudscraper** — fetching government list endpoints that require a browser-like TLS fingerprint
- **Streamlit Community Cloud / GitHub Actions** — deployment

## How It Works

1. On startup, the app fetches each list live from its official source (with a one-hour cache).
2. **Five-strategy matching engine** — exact, alias, substring, fuzzy (token-set), and phonetic — scores every candidate.
3. Thresholds (configurable in the sidebar) decide whether a name is a **HIT**, **POTENTIAL HIT**, or **NO HIT**.
4. Results exportable as PDF, CSV, and XLSX, with a data-provenance table showing exactly when each list was fetched.
5. If a source is temporarily unavailable, the last snapshot in `data/` is used and the UI shows a "cached" status instead of failing.

## Screening Sources

| Source | Coverage |
| ------ | -------- |
| OFAC SDN List | US Office of Foreign Assets Control - Specially Designated Nationals |
| OFAC Non-SDN List | US consolidated non-SDN sanctions list |
| UN Consolidated List | United Nations Security Council consolidated sanctions list |
| Australian DFAT List | Australian Department of Foreign Affairs and Trade consolidated list |
| MAS Designated Lists | Monetary Authority of Singapore - designated individual and entity regimes |
| MAS Enforcement Actions | Monetary Authority of Singapore enforcement actions |
| SG TSFA First Schedule | Singapore Terrorism (Suppression of Financing) Act 2002, First Schedule |
| MAS Investor Alert List | Monetary Authority of Singapore - unlicensed entities flagged for potentially misrepresenting their status (investor-protection list, not a sanctions list) |

The TSFA First Schedule incorporates the UN Taliban and ISIL (Da'esh) / Al-Qaida lists, which are already screened through the UN Consolidated List source. The SG TSFA source therefore contributes the named individuals from Schedule 1, paragraph 2.

## Getting Started (Local)

Requirements: Python 3.10 or later.

1. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

2. Launch the application:

   ```
   python -m streamlit run app.py
   ```

3. Open the local URL printed in the terminal (by default `http://localhost:8501`).

## Project Structure

```
app.py                 Application entry point and user interface
config.py              Source URLs, labels, and matching thresholds
matcher.py             Name matching engine and confidence scoring
report.py              PDF report generation
sources/               One module per sanctions source
data/                  Snapshot files used as a fallback (regenerated on fetch)
.streamlit/            Streamlit configuration and theme
requirements.txt       Python dependencies
```

---

## Privacy and Data Handling

No names are stored or transmitted outside the application. Screening runs entirely within the hosted application; records are matched in memory and discarded at the end of each session. Name matching is performed on your own machine or your own hosted environment.

---

## Disclaimer

Screening results are advisory and generated by automated name-matching algorithms. Matches require human review and confirmation against the underlying source records before any action is taken. Absence of a match does not confirm a subject is unsanctioned.
